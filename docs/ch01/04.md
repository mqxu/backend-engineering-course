# 四、DevTools：改完代码不用手动重启

开发期反复重启应用很耗时间，Spring Boot 提供的 DevTools 能在类文件变化时自动重启：

`pom.xml（追加）`

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```

> **它为什么快，以及为什么打不进生产包**
>
> **原理：**DevTools 用两个类加载器 —— 一个加载不会变的第三方依赖，一个加载你自己的类。重启时只丢弃并重建后者，所以比冷启动快得多。
>
> **打包行为：**只要声明了 `<optional>true</optional>`，DevTools 就不会被打进可执行 jar，也不会传递给依赖你的其他项目 —— 这是它默认的设计，不需要额外配置。用 `java -jar` 启动时，DevTools 还会自动判断为“生产模式”而关闭。

另外，DevTools 还带来两个实用功能：静态资源（模板、图片）修改后无需重启即可生效；内置 LiveReload 服务器，配合浏览器插件可自动刷新页面。

# 10.13 问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `/actuator/metrics` 返回 404 | 默认只暴露 `health` | 写进 `exposure.include` |
| `include: *` 启动就报 YAML 解析失败 | `*` 是 YAML 别名语法 | 写成 `include: "*"` |
| 端点返回 404 而不是 403 | 端点没注册路由，不在安全层 | 查 `exposure.include`，别查安全配置 |
| 端点返回 403 | 被安全层拦了 | 查 `SecurityFilterChain` 与角色 |
| 找不到符号 `HealthIndicator` | 4.x 换了包与模块 | `org.springframework.boot.health.contributor` |
| 找不到符号 `MeterRegistryCustomizer` | 4.x 换了包 | `org.springframework.boot.micrometer.metrics.autoconfigure` |
| 找不到符号 `EndpointRequest` | 4.x 换了模块与包，旧位置已删除 | `org.springframework.boot.security.autoconfigure.actuate.web.servlet` |
| `/actuator/health` 只有 `{"status":"UP"}` | `show-details` 默认 `never` | 按需改 `always` 或 `when-authorized` |
| 配了 `info.app.*` 但响应里没有 `app` | `management.info.env.enabled` 默认关 | 显式打开 |
| `/actuator/info` 里没有 `build` 段 | 没有 `META-INF/build-info.properties` | 加 `build-info` goal |
| 探针端点 404 | `probes.enabled` 没开 | 打开；K8s 里探针要指向 `health/liveness`、`health/readiness` |
| 外部依赖抖动导致实例被重启 | liveness 组里塞了外部依赖 | 只留 `livenessState` |
| 就绪组状态是 `DOWN` 不是 `OUT_OF_SERVICE` | 组状态按包含的组件聚合 | 显式配 `group.*.status.http-mapping` |
| 改级别后日志没变多 | `effectiveLevel` 被父级压住 | 看 `configuredLevel` 与 `effectiveLevel` 的差异 |
| 读了 `configuredLevel` 得到 null | `null` 时该键整个从响应消失 | 改成对响应体文本断言 |
| JsonPath 取不到带点的 logger 名 | 点被当成分层 | 用 `['com.example.resourcehub']` 写法 |
| `curl` 查带方括号的 logger 名失败 | 方括号被当 glob | 加 `-g` 或做百分号编码 |
| 列表里有 `_org` 这种名字 | 框架的隐藏 logger，下划线是名字的一部分 | 需要时按原样单独调级 |
| `Gauge` 值是条水平直线 | 传了当前值而不是取值函数 | 用三参数重载，传 `ToDoubleFunction` |
| Prometheus 里多出一条 0 值时间线 | 同名 meter 用不同标签组合 | 标签组合在构造时一次建全 |
| 看板上指标名对不上 | 导出时名字被规范化 | 点→下划线、Counter 补 `_total`、Timer 补 `_seconds` |
| 测试里 `/actuator/prometheus` 404、运行时正常 | 测试模块默认换掉真实导出 | `spring.test.metrics.export=true` |
| 启动失败提示 `management.tracing.enabled` | 4.x 已废弃且为 error 级 | 改成 `management.tracing.export.enabled` |
| `@Observed` 不生效 | 注解观测默认关闭 | `management.observations.annotations.enabled=true` |
| Timer 算不出 P99 | 没开直方图 | `management.metrics.distribution.percentiles-histogram.*` |
| 时间线数量暴涨 | 开了全局直方图或加了高基数标签 | 只给关键指标开；标签只用低基数维度 |

# 九、不把实体直接返回

`dto/UserResponse.java`

```java
public record UserResponse(Long id, String username, String nickname, String role, String roleLabel) {

    public static UserResponse from(AppUser user) {
        return new UserResponse(
                user.getId(),
                user.getUsername(),
                user.getNickname(),
                user.getRole().name(),
                user.getRole().getLabel()
        );
    }
}
```

`AppUser` 实体带着 BCrypt 密码哈希。**直接返回实体会把哈希暴露给前端**——虽然 BCrypt 不能直接反解，但攻击者拿到哈希就能离线慢慢爆破，等于白白送出一份素材。

用 DTO 明确列出“哪些字段可以对外”，是防止这类泄漏最直接的办法。测试里也专门加了一条断言守住它：

```java
.andExpect(jsonPath("$.data.user.password").doesNotExist());
```

# 八、401/403 要返回 JSON

不处理这两个分支，Spring Security 默认返回 HTML 登录页或空响应体。

`security/RestSecurityErrorHandler.java`

```java
@Component
public class RestSecurityErrorHandler implements AuthenticationEntryPoint, AccessDeniedHandler {

    private final ObjectMapper objectMapper;

    public RestSecurityErrorHandler(ObjectMapper objectMapper) {
        this.objectMapper = objectMapper;
    }

    /** 未认证：没带令牌、令牌过期、令牌签名不对 */
    @Override
    public void commence(HttpServletRequest request, HttpServletResponse response,
                         AuthenticationException authException) throws IOException {
        write(response, HttpStatus.UNAUTHORIZED, 40100, "未登录或登录已过期，请重新登录");
    }

    /** 已认证但权限不足 */
    @Override
    public void handle(HttpServletRequest request, HttpServletResponse response,
                       AccessDeniedException accessDeniedException) throws IOException {
        write(response, HttpStatus.FORBIDDEN, 40300, "没有权限执行该操作");
    }

    private void write(HttpServletResponse response, HttpStatus status, int code, String message)
            throws IOException {
        response.setStatus(status.value());
        // 必须显式指定字符集，否则中文提示会乱码
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding(StandardCharsets.UTF_8.name());
        response.getWriter().write(
                objectMapper.writeValueAsString(ApiResponse.fail(code, message)));
    }
}
```

**真实响应**（未登录）：

```
HTTP 401
{"code":40100,"message":"未登录或登录已过期，请重新登录"}
```

（普通用户越权）：

```
HTTP 403
{"code":40300,"message":"没有权限执行该操作"}
```

> **`setCharacterEncoding` 不能省**
>
> 只设 `Content-Type: application/json` 而不设字符集，中文提示会变成乱码。Spring MVC 的 `MappingJackson2HttpMessageConverter` 会自动处理，但这里是自己直接写响应流，得手动设。

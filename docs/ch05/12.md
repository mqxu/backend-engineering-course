# 十二、本章实测汇总

| 场景 | 请求 | 结果 |
| --- | --- | --- |
| 管理员登录 | `POST /api/auth/login` | 200，返回 token（232 字符）、`expiresIn: 7200`、用户信息 |
| 密码错误 | `POST /api/auth/login` | 401，`40100`，“用户名或密码错误” |
| 用户名不存在 | `POST /api/auth/login` | 401，提示与密码错误**完全一致** |
| 注册成功 | `POST /api/auth/register` | 201，`role` 固定为 `USER` |
| 重复注册 | `POST /api/auth/register` | 409，`40900` |
| 弱密码注册 | `password: "12345678"` | 400，“密码必须同时包含字母和数字” |
| 未登录新增 | 无 `Authorization` 头 | **401**，`40100`，JSON 而非登录页 |
| 普通用户新增 | 带 USER 令牌 | **403**，`40300` |
| 管理员新增 | 带 ADMIN 令牌 | **201** |
| 管理员删除 | 带 ADMIN 令牌 | 200，删除后再查 404 |
| 游客查列表 | 无令牌 | 200（公开接口） |
| 未登录报名通过 | 无令牌 | 401 |
| 普通用户报名通过 | 带 USER 令牌 | 200 |
| 游客访问 metrics | 无令牌 | 401 |
| 游客访问 health | 无令牌 | 200（探针需要） |
| 篡改 payload 提权 | 把 `role` 改成 `ADMIN`，签名不变 | **401**（签名校验失败） |
| `alg=none` 攻击 | header 改成 `{"alg":"none"}` | **401**（不被接受） |
| 当前用户 | `GET /api/auth/me` | 200，返回 id/username/nickname/role |

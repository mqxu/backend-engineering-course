# 一、认证与授权是两个问题

先分清两个词，后面所有配置都围绕它们：

| | 认证（Authentication） | 授权（Authorization） |
| --- | --- | --- |
| 回答的问题 | 你是谁？ | 你能做什么？ |
| 失败的状态码 | **401 Unauthorized** | **403 Forbidden** |
| 失败原因 | 没带凭证、凭证无效或过期 | 凭证有效，但角色不够 |
| 前端应对 | 跳登录页 | 提示“无权限”，不要跳登录 |

**401 与 403 混用是很常见的错误**：用户明明登录了，却收到 401 被踢回登录页，怎么登都进不去——实际是权限不够，应该是 403。前端拿到 401 才清令牌跳登录，拿到 403 只提示。

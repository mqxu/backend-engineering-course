# 十三、常见问题

| 症状 | 原因与解法 |
| --- | --- |
| 所有请求 401，包括公开接口 | 过滤链里漏了 `permitAll()`，或 `anyRequest()` 写在了具体规则前面 |
| 所有 POST 返回 403 且提示看不懂 | 忘了 `csrf().disable()`（无状态令牌认证场景下应关掉） |
| 登录了却是 403 | `getAuthorities()` 少了 `ROLE_` 前缀；或 `hasRole` 与 `hasAuthority` 混用（见第十一节） |
| 未登录时返回 HTML 而不是 JSON | 没配 `authenticationEntryPoint` |
| 中文提示乱码 | 写响应流时漏了 `setCharacterEncoding("UTF-8")` |
| 启动报 `WeakKeyException` | JWT 密钥不足 32 字节 |
| 运行时报 `Unable to discover an implementation` | jjwt 只引了 `jjwt-api`，缺 `jjwt-impl` |
| 前端跨域配置失效 | 引入 Security 后 CORS 必须配在 Security 里（`CorsConfigurationSource`），`WebMvcConfigurer#addCorsMappings` 会与它冲突产生重复响应头 |
| 启动日志出现 `UserDetailsService beans will not be used...` 的 WARN | 手动声明了 `AuthenticationProvider` Bean，自动配置退让了。删掉自己的 Provider，交给自动配置 |
| MockMvc 测试全部 401 | 缺 `spring-boot-starter-security-test`；或请求没加 `.with(user(...))` |
| `@AuthenticationPrincipal` 注入 null | 测试里传的主体类型与 Controller 声明的类型不一致 |
| 改了角色但接口权限没变 | 令牌里存的是签发时的角色，要等令牌过期或重新登录 |
| 想让用户立刻下线却做不到 | 无状态令牌的固有限制，需引入 refreshToken + 黑名单或改用会话认证 |

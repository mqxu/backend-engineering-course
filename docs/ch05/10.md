# 十、测试怎么带身份

### 10.1 引入 Security 后测试全挂

这是必然的。项目里加完 `spring-boot-starter-security`，原有测试立刻变成这样（本机真实输出）：

```
[ERROR] Tests run: 21, Failures: 11, Errors: 0, Skipped: 0 <<< FAILURE!
[ERROR]   ResourceApiTest.createResource:130  Status expected:<201> but was:<401>
[ERROR]   ResourceApiTest.deleteResource:232  Status expected:<200> but was:<401>
[ERROR]   ResourceApiTest.updateResource:221   Status expected:<200> but was:<401>
[ERROR]   ResourceApiTest.systemInfo:285       Status expected:<200> but was:<401>
```

**11 个失败全是 401**。不是接口坏了，是测试请求没带身份——安全过滤链在测试环境下同样生效。

### 10.2 补两件事

**一、加测试依赖**：

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security-test</artifactId>
    <scope>test</scope>
</dependency>
```

4.x 为它单独提供了 starter，会传递引入 `spring-security-test` 与 `spring-boot-security-test`。

**二、给请求加模拟身份**：

```java
import static org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestPostProcessors.user;

/** 模拟一个已登录的管理员（权限名 ROLE_ADMIN，对应 hasRole("ADMIN")） */
private static RequestPostProcessor admin() {
    return user("admin").roles("ADMIN");
}

/** 模拟一个已登录的普通用户（ROLE_USER），用来验证权限边界 */
private static RequestPostProcessor student() {
    return user("student").roles("USER");
}
```

用法：

```java
mockMvc.perform(post("/api/resources").with(admin())
                .contentType(MediaType.APPLICATION_JSON)
                .content(VALID_CREATE_BODY))
        .andExpect(status().isCreated());

mockMvc.perform(post("/api/resources").with(student())     // 权限不足
                .contentType(MediaType.APPLICATION_JSON)
                .content(VALID_CREATE_BODY))
        .andExpect(status().isForbidden())
        .andExpect(jsonPath("$.code").value(40300));
```

### 10.3 权限边界也要测

**未登录**与**权限不足**是两条不同的路径，都要有测试：

```java
@Test
@DisplayName("新增资源：未登录返回 401，响应体是 JSON 而不是登录页")
void createWithoutLogin() throws Exception {
    mockMvc.perform(post("/api/resources")
                    .contentType(MediaType.APPLICATION_JSON)
                    .content(VALID_CREATE_BODY))
            .andExpect(status().isUnauthorized())
            .andExpect(jsonPath("$.code").value(40100));
}

@Test
@DisplayName("新增资源：普通用户权限不足返回 403（注意与 401 的区别）")
void createAsNormalUser() throws Exception { ... }

@Test
@DisplayName("Actuator：metrics 端点需要管理员权限")
void metricsRequiresAdmin() throws Exception {
    mockMvc.perform(get("/actuator/metrics"))
            .andExpect(status().isUnauthorized());
    mockMvc.perform(get("/actuator/metrics").with(admin()))
            .andExpect(status().isOk());
}
```

> **`@AuthenticationPrincipal` 的类型必须对得上**
>
> 如果 Controller 写的是 `@AuthenticationPrincipal AuthUser principal`，测试里用 `user("admin").roles("ADMIN")`（Spring 默认的 `User` 类型）就会注入 **null**，报出 NPE 而看不出原因。
>
> 正确写法是传项目自己的主体类型：
>
> ```java
> mockMvc.perform(get("/api/auth/me")
>                 .with(user(AuthUser.fromToken(1L, "admin", "ROLE_ADMIN"))))
>         .andExpect(status().isOk());
> ```

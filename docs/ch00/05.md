# 五、本教程的代码约定

为了不在每篇重复解释，这里把全局约定一次讲清，后续章节直接遵循。

| 约定 | 内容 | 原因 |
| --- | --- | --- |
| 包名 | `com.example.resourcehub` | 占位用法。实际项目替换成自己的组织域名倒写 |
| 统一响应体 | `ApiResponse<T>`，字段为 `code` / `message` / `data`，`code = 0` 表示成功 | 前端只需判断一个字段就能区分成功与失败 |
| 分页结果 | `PageResult<T>`，字段为 `items` / `total` / `page` / `size` | 不直接暴露框架的分页对象，避免换数据访问技术时接口跟着变 |
| HTTP 状态码 | 传输层语义用状态码（200 / 201 / 400 / 404），业务语义用 `code` | 两者分工明确，网关和前端都能各自利用 |
| 时间类型 | 实体统一用 `LocalDateTime`，对外格式由字段上的 `@JsonFormat` 指定 | `spring.jackson.date-format` 对 JSR-310 类型不生效，必须用注解 |
| 实体标识 | 业务表统一带 `created_at` / `updated_at`；删除采用状态字段而非物理删除 | 便于审计与恢复 |

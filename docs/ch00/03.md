# 三、环境准备

### 3.1 JDK

Spring Boot 4.1 要求 JDK 17 及以上，兼容至 26。教程统一使用 **JDK 21 LTS** —— LTS 版本意味着长期安全更新，教学与生产都合适。

```bash
java -version
```

```text
openjdk version "21.0.12.1" 2026-08-18 LTS
OpenJDK Runtime Environment (build 21.0.12.1+1-LTS)
OpenJDK 64-Bit Server VM (build 21.0.12.1+1-LTS, mixed mode, sharing)
```

机器上装了多个 JDK 时，用工具管理并随时切换：macOS 可以用 `jenv` 或 `/usr/libexec/java_home`，Windows 用 IDE 的 SDK 配置或环境变量。查看本机已装的 JDK 列表：

```bash
# macOS
/usr/libexec/java_home -V

# 临时指定某个 JDK 跑 Maven（不改全局环境变量）
JAVA_HOME=/path/to/jdk-21 mvn clean test
```

### 3.2 Maven 与国内镜像

Maven 版本要求 3.6.3 及以上，教程使用 3.9.11：

```text
Apache Maven 3.9.11 (3e54c93a704957b63ee3494413a2b544fd3d825b)
Maven home: /opt/homebrew/Cellar/maven/3.9.11/libexec
Java version: 21.0.12.1, vendor: BellSoft
Default locale: zh_CN, platform encoding: UTF-8
OS name: "mac os x", arch: "aarch64"
```

国内下载依赖建议配置镜像。配置文件位于 `~/.m2/settings.xml`（没有就新建）：

`~/.m2/settings.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.2.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.2.0
          https://maven.apache.org/xsd/settings-1.2.0.xsd">
  <localRepository>${user.home}/.m2/repository</localRepository>
  <mirrors>
    <mirror>
      <id>aliyun-central</id>
      <mirrorOf>central</mirrorOf>
      <name>阿里云中央仓库</name>
      <url>https://maven.aliyun.com/repository/central</url>
    </mirror>
  </mirrors>
</settings>
```

> **镜像配置的一个常见误区**
>
> 把 `<mirrorOf>` 写成 `*` 会拦截**所有**仓库请求，包括镜像站本身不具备的私有仓库。只镜像 `central` 通常就够了。如果确实需要兜底，再加一条 `public` 仓库的镜像，而不是用 `*` 一把抓。

### 3.3 环境自检

三条命令确认环境就绪：

```bash
java -version            # 期望：21.x
mvn -v                   # 期望：Maven 3.6.3+，且 Java version 指向 21
mvn help:evaluate -Dexpression=java.version -q -DforceStdout   # 看 Maven 实际使用的 JDK
```

> **最容易踩的环境坑**
>
> `mvn -v` 里显示的 Java 版本，可能与你 `java -version` 看到的不是同一个。Maven 用的是 `JAVA_HOME`，而命令行用的是 `PATH` 里的 java。两者不一致时，会出现“命令行编译没问题、IDE 报版本不兼容”这类怪现象。先对齐这两个，再开始写代码。

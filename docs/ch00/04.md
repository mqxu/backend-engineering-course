# 四、贯穿全教程的案例项目

### 4.1 业务说明

教程只讲一个业务：**资源分享应用**。教师和学生上传教学资源（文档、视频、压缩包），按分类归档、按关键词检索、统计下载量。选择它做主线，是因为它同时具备三个特征：

**业务足够简单**

核心只有分类、资源、下载记录三个概念，不需要花时间理解业务背景，注意力可以全部放在技术实现上。

**场景足够真实**

覆盖后端开发的高频场景：分页与多条件检索、文件上传下载、下载量统计、权限控制、缓存热点数据。

**能自然长大**

从最简单的 REST 接口起步，一路加上校验、安全、缓存、消息、监控、容器化，每个技术点都有合适的落点。

### 4.2 数据模型

两张核心表，外加一张可选的下载记录表（第 6 篇引入）。

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `category` 分类 | id、name、code、sort_order、created_at | 资源分类，如“后端开发”“前端开发”。`code` 用于对外接口，避免暴露自增主键 |
| `resource_item` 资源 | id、title、description、category_id、type、url、file_size、download_count、uploader、tags、enabled、created_at、updated_at | 核心业务表。`type` 是枚举（文档 / 视频 / 代码 / 外部链接），`enabled` 用于逻辑删除 |
| `download_record` 下载记录 | id、resource_id、user_id、ip、created_at | 第 6 篇引入，用于统计与审计。本教程前几篇先只用资源表上的计数字段 |

### 4.3 分层结构

工程采用按技术职责分层，包结构如下（第 2 篇会详细解释这个划分的依据）：

`包结构（com.example.resourcehub）`

```bash
com.example.resourcehub
├── ResourceHubApplication.java     主类，位于根包
├── common/                          通用组件：响应体、分页结果、异常、全局异常处理
│   ├── ApiResponse.java
│   ├── PageResult.java
│   ├── BusinessException.java
│   └── GlobalExceptionHandler.java
├── config/                          配置类：属性绑定、Web 配置、安全配置
├── domain/                          领域模型：实体与枚举
├── repository/                      数据访问：Spring Data 仓库接口
├── service/                         业务逻辑
├── dto/                             数据传输对象：请求与响应模型
└── web/                             控制器：只做协议转换
```

### 4.4 技术选型

| 层次 | 选型 | 理由 |
| --- | --- | --- |
| 后端框架 | Spring Boot 4.1.1 | 教程主线 |
| 数据访问 | Spring Data JPA（主线） MyBatis-Plus 3.5.17（对照） | JPA 是官方主线，便于对照文档；MyBatis-Plus 是国内团队常用，第 6 篇做等价实现对照 |
| 数据库 | H2（教学） MySQL 8（部署） | H2 内存库免安装、免建表，让读者把注意力放在代码上；第 11 篇切换到 MySQL 演示真实部署 |
| 接口风格 | REST + JSON | 前后端分离的基础，第 12 篇的 Vue 前端直接消费 |
| 认证 | Spring Security + JWT | 无状态、适合前后端分离；第 5 篇实现 |
| 前端 | Vue 3 + Vite + Element Plus + Pinia | 国内主流组合，与多数院校课程技术栈一致；第 12 篇实现 |
| 构建 | Maven（后端） Vite（前端） | —— |

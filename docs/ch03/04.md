# 四、日志

### 4.1 默认行为已经够用

Spring Boot 默认使用 Logback，输出到控制台，默认级别 INFO，日志格式包含时间、级别、进程号、应用名、线程名、类名。你在前面章节看到的所有日志都是默认配置的输出，没有任何额外设置。

### 4.2 调整级别

`application.yml`

```yaml
logging:
  level:
    root: info
    com.example.resourcehub: debug      # 只给自己的包开 debug
    org.hibernate.SQL: debug            # 打印实际执行的 SQL
    org.hibernate.orm.jdbc.bind: trace  # 打印 SQL 参数绑定值
```

案例工程把这两行注释掉了，需要看 SQL 时再打开：

`resource-hub 的 application.yml（节选）`

```yaml
logging:
  level:
    root: info
    com.example.resourcehub: debug
    # 想看实际发出的 SQL 就打开这两行
    # org.hibernate.SQL: debug
    # org.hibernate.orm.jdbc.bind: trace
```

> **注意 Hibernate 7 的日志类名变了**
>
> 参数绑定的日志类别是 `org.hibernate.orm.jdbc.bind`，而 5.x 时代是 `org.hibernate.type.descriptor.sql`。照抄老教程的日志配置，会出现“SQL 打得出来、参数打不出来”的情况。

### 4.3 日志分组

几个相关的包要一起调级别时，用分组更省事：

`application.yml`

```yaml
logging:
  group:
    myapp: com.example.resourcehub.controller,com.example.resourcehub.service
    hibernate: org.hibernate.orm.core,org.hibernate.orm.jdbc
  level:
    myapp: debug
    hibernate: info
```

### 4.4 输出到文件与滚动

`application.yml`

```yaml
logging:
  file:
    name: /var/log/resource-hub/app.log
  logback:
    rollingpolicy:
      max-file-size: 50MB          # 单个文件上限
      max-history: 30              # 保留 30 天
      total-size-cap: 2GB          # 全部日志文件总上限
```

> **生产环境务必设这三个上限**
>
> 只配 `file.name` 而不限制大小和历史，服务器磁盘迟早被日志写满 —— 这是很常见的线上故障。三个参数各管一件事，建议一起配上。

### 4.5 结构化日志

日志要接入 ELK、Loki 这类平台时，JSON 格式比纯文本好解析得多：

`application.yml`

```yaml
logging:
  structured:
    format:
      console: ecs        # 或 logstash、gelf
```

开启后每条日志变成一行 JSON，字段包含时间戳、级别、logger、消息、线程等，采集端不需要写正则表达式去解析。

### 4.6 自定义 Logback 配置

需要更精细的控制（多个 appender、按业务分文件、自定义格式）时，用 `logback-spring.xml`：

`src/main/resources/logback-spring.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <include resource="org/springframework/boot/logging/logback/defaults.xml"/>

    <!-- 只在 dev 环境启用的 appender -->
    <springProfile name="dev">
        <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
            <encoder>
                <pattern>%d{HH:mm:ss.SSS} %-5level [%thread] %logger{36} - %msg%n</pattern>
            </encoder>
        </appender>
        <root level="INFO">
            <appender-ref ref="CONSOLE"/>
        </root>
    </springProfile>
</configuration>
```

> **文件名必须是 logback-spring.xml，不是 logback.xml**
>
> 用 `logback.xml` 时 Logback 会在 Spring 启动**之前**加载它，此时 `<springProfile>` 和 `<springProperty>` 这些扩展标签不可用（因为还不认识它们）。要享受 Spring 的扩展能力，必须用 `logback-spring.xml`。

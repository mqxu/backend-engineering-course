# 七、AOP：切面编程

官方文档对 AOP 只有简短一节，但它在实际项目里出现频率很高 —— 操作日志、性能监控、权限校验都常用切面实现。

### 7.1 依赖坐标变了

`pom.xml`

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aspectj</artifactId>
</dependency>
```

4.x 用的是 `spring-boot-starter-aspectj`。如果你的项目里写的是别的名字，以官方 starter 清单为准。

### 7.2 一个实用的切面：记录接口调用

`common/WebLogAspect.java`

```java
package com.example.resourcehub.common;

import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Component;

@Aspect
@Component
public class WebLogAspect {

    private static final Logger log = LoggerFactory.getLogger(WebLogAspect.class);

    /** 拦截 web 包下所有控制器方法 */
    @Around("execution(* com.example.resourcehub.web..*(..))")
    public Object logAround(ProceedingJoinPoint joinPoint) throws Throwable {
        String method = joinPoint.getSignature().toShortString();
        long start = System.currentTimeMillis();
        try {
            Object result = joinPoint.proceed();
            log.info("{} 执行完成，耗时 {} ms", method, System.currentTimeMillis() - start);
            return result;
        } catch (Throwable e) {
            log.warn("{} 执行异常：{}", method, e.getMessage());
            throw e;
        }
    }
}
```

> **切面的三个使用原则**
>
> **一、切点要尽量具体。**写成 `execution(* com..*(..))` 会拦截一切，性能损耗和调试困难都会随之而来。
>
> **二、不要在切面里吞异常。**上面用 `catch → log → throw`，异常继续往上抛，全局异常处理器还能正常工作。
>
> **三、注意自调用失效。**同类内部方法互相调用不经过代理，切面不会生效 —— 这和事务失效是同一个原因，第 6 篇会详述。

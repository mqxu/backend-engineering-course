# 九、其他特性要点

### 9.1 定制 SpringApplication

**启动时的常见定制**

```java
public static void main(String[] args) {
    SpringApplication app = new SpringApplication(ResourceHubApplication.class);

    // 关闭启动横幅
    app.setBannerMode(Banner.Mode.OFF);

    // 默认属性（优先级最低，仅作为缺省值）
    app.setDefaultProperties(Map.of("resource-hub.default-uploader", "system"));

    // 关闭懒加载（默认即关闭，开启可加快启动但会推迟错误暴露）
    // app.setLazyInitialization(true);

    app.run(args);
}
```

常用的命令行开关：

| 参数 | 作用 |
| --- | --- |
| `--debug` | 打印自动配置条件评估报告（第 2 篇用过） |
| `--trace` | 打印更详细的追踪日志 |
| `--server.port=9090` | 覆盖端口 |
| `--spring.profiles.active=prod` | 指定环境 |
| `--spring.config.location=file:/etc/app/` | 指定外部配置目录 |

### 9.2 SSL

`application.yml`

```yaml
server:
  port: 8443
  ssl:
    enabled: true
    key-store: classpath:keystore.p12
    key-store-password: ${KEYSTORE_PASSWORD}
    key-store-type: PKCS12
    key-alias: resource-hub
```

生成自签名证书用于本地测试：

```bash
keytool -genkeypair -alias resource-hub -keyalg RSA -keysize 2048 \
  -storetype PKCS12 -keystore keystore.p12 -validity 3650 \
  -dname "CN=localhost" -storepass changeit
```

> **生产环境通常在网关层做 HTTPS**
>
> 把证书配在应用里意味着证书轮换要重启应用。更常见的做法是 Nginx 或云负载均衡终止 TLS，应用只监听内网 HTTP。第 11 篇部署部分会给出 Nginx 的完整配置。

### 9.3 Dev Services 与 Docker Compose

官方文档中提到 Dev Services 与 Docker Compose 支持：开发期可以用 Docker Compose 声明依赖的中间件（数据库、Redis、消息队列），Spring Boot 启动时自动拉起容器并在关闭时停止。

`compose.yml`

```yaml
services:
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
```

`pom.xml`

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-docker-compose</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```

引入依赖后启动应用，它会自动执行 `docker compose up`，并把连接信息注入配置。**前提是本机装了 Docker**；没有 Docker 时这部分跳过即可，第 6 篇的 NoSQL 一节会给出不依赖 Docker 的替代方案。

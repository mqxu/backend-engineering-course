# 五、JSON 序列化

### 5.1 默认行为

引入 Web starter 后，Jackson 3 自动配置好，控制器返回的对象会被自动序列化为 JSON。案例工程的响应体长这样：

```bash
curl -s "http://localhost:8080/api/resources?size=1"
```

```text
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 5,
        "title": "Spring Boot 官方文档（online）",
        "description": "官方参考文档入口，版本随官方发布同步更新。",
        "categoryId": 5,
        "categoryName": "外部链接",
        "type": "LINK",
        "typeLabel": "外部链接",
        "url": "https://docs.spring.io/spring-boot/",
        "fileSizeText": "-",
        "downloadCount": 312,
        "uploader": "陶老师",
        "tags": "官方文档,参考",
        "createdAt": "2026-08-20 08:00:00",
        "updatedAt": "2026-08-20 08:00:00"
      }
    ],
    "page": 0,
    "size": 1,
    "total": 5,
    "totalPages": 5
  }
}
```

这份响应里有几处值得留意的设计：

| 现象 | 背后的处理 |
| --- | --- |
| 没有出现任何 `null` 字段 | `default-property-inclusion: non_null` 生效，响应体更干净 |
| `createdAt` 是 `"2026-08-20 08:00:00"` 而不是带 `T` 的 ISO 格式 | 字段上加了 `@JsonFormat`，因为 `date-format` 对 `LocalDateTime` 无效 |
| 既有 `type` 又有 `typeLabel` | 枚举值给程序判断，中文标签给界面展示 |
| `fileSizeText` 是 `"-"` 而不是数字 | 外部链接型资源没有文件大小，DTO 里做了展示层的格式化 |

### 5.2 常用配置项

| 配置项 | 作用 | 本案例是否使用 |
| --- | --- | --- |
| `spring.jackson.default-property-inclusion` | 控制值为 null 的字段是否输出 | 用了 `non_null` |
| `spring.jackson.property-naming-strategy` | 字段命名策略（如转下划线） | 未用，保持驼峰 |
| `spring.jackson.date-format` | 日期格式 | **不用**，对 JSR-310 类型无效 |
| `spring.jackson.deserialization.fail-on-unknown-properties` | 未知字段是否报错 | 未用，默认忽略 |

> **三个 4.x 特有的坑**
>
> **坑一：`write-dates-as-timestamps` 会导致启动失败。**该枚举已从 `SerializationFeature` 移到 `DateTimeFeature`，而 Spring Boot 4.1 的 `JacksonProperties` 没暴露这个配置项。写了就报 `No enum constant tools.jackson.databind.SerializationFeature.write-dates-as-timestamps`。删掉即可，Jackson 3 默认输出 ISO-8601。
>
> **坑二：`date-format` 对 `LocalDateTime` 无效。**它只作用于 `java.util.Date`。JSR-310 类型的格式必须在字段上用 `@JsonFormat`：
>
> **正确做法**
>
> ```java
> @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")
> private LocalDateTime createdAt;
> ```
>
> **坑三：`ObjectMapper` 换包了。**手写 Jackson 配置代码时，import 要从 `com.fasterxml.jackson.databind` 改成 `tools.jackson.databind`。注解包 `com.fasterxml.jackson.annotation` 不变。

### 5.3 常用注解

| 注解 | 作用 | 示例 |
| --- | --- | --- |
| `@JsonFormat` | 指定日期时间格式 | `@JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")` |
| `@JsonProperty` | 指定 JSON 字段名（3.x 中包名不变） | `@JsonProperty("download_count")` |
| `@JsonIgnore` | 序列化与反序列化都忽略 | 敏感字段 |
| `@JsonInclude` | 字段级控制空值输出 | `@JsonInclude(NON_NULL)` |
| `@JsonIgnoreProperties` | 忽略未知字段 | `ignoreUnknown = true` |

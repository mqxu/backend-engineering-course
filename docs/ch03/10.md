# 十、常见问题

| 症状 | 原因与解法 |
| --- | --- |
| 配置改了不生效 | 按优先级逐层排查：命令行参数 → 环境变量 → 包外配置 → 包内配置。启动日志里看激活的 Profile 是不是预期的那个 |
| 注入 `AppProperties` 报找不到 Bean | 漏了 `@ConfigurationPropertiesScan` 或 `@EnableConfigurationProperties` |
| yml 里的自定义配置项没有 IDE 提示 | 缺 `spring-boot-configuration-processor` 依赖，或编译后未重新索引 IDE |
| 启动报 `No enum constant ... write-dates-as-timestamps` | 删掉该配置项，Jackson 3 已不需要 |
| `LocalDateTime` 输出成 `2026-09-13T15:47:38` 带 T | 在字段上加 `@JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")` |
| 异步方法没有异步执行 | 同类内部调用、方法非 public、或漏了 `@EnableAsync` |
| 定时任务到点没执行 | 漏了 `@EnableScheduling`；或类不是 Spring Bean（没有组件注解） |
| 自定义 `logback-spring.xml` 的 `<springProfile>` 不识别 | 文件名写成了 `logback.xml`，改成 `logback-spring.xml` |

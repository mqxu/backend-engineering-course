# 六、国际化

`src/main/resources/messages.properties`

```properties
resource.notfound=资源不存在
resource.title.duplicate=标题已存在：{0}
validation.title.notblank=标题不能为空
```

`src/main/resources/messages_en.properties`

```properties
resource.notfound=Resource not found
resource.title.duplicate=Title already exists: {0}
```

`application.yml`

```yaml
spring:
  messages:
    basename: messages          # 默认值，指向 classpath:messages.properties
    encoding: UTF-8
    fallback-to-system-locale: false
```

在代码里按当前语言取文案：

**使用 MessageSource**

```java
@Service
public class ResourceService {

    private final MessageSource messageSource;

    public ResourceService(MessageSource messageSource) {
        this.messageSource = messageSource;
    }

    public void checkExists(Long id) {
        if (!resourceRepository.existsById(id)) {
            String msg = messageSource.getMessage("resource.notfound", null, LocaleContextHolder.getLocale());
            throw new BusinessException(40401, msg);
        }
    }
}
```

> **中文乱码？先检查这三处**
>
> 一、`messages.properties` 是否以 UTF-8 保存（IDEA 里 Settings → File Encodings 要勾上 “Transparent native-to-ASCII conversion” 或直接使用 `messages_zh_CN.properties`）。
> 二、`spring.messages.encoding` 是否设为 UTF-8。
> 三、`ResourceBundleMessageSource` 的默认编码历史上是 ISO-8859-1，配置项写错就会乱码。

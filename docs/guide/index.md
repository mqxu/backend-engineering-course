# 课程导读

这套教程按 Spring Boot 官方文档 4.1.x 的章节顺序重写，终点是一个前后端分离的全端项目：Spring Boot 4 后端 + Vue 3 管理端。正文里的代码全部来自本机实际编译、启动、验证过的工程，不是从文档里摘的片段。

版本基线：Spring Boot **4.1.1** · Spring Framework **7.0.9** · Java **21 LTS** · Maven **3.9.11**。

## 官方文档缺什么

| 官方文档的形态 | 学习时的实际困难 |
| --- | --- |
| 按特性逐条罗列，一个特性一小节 | 读完之后，不知道这些特性在一个项目里怎么拼起来 |
| 代码片段多为最小示例 | 片段散落在各章，缺少"同一个项目从零长起来"的连续感 |
| API 文档六万余页 | 能查到类名和方法签名，但判断不出什么时候该用哪一个 |
| 版本变更写在发布说明里 | 3.x 的写法在 4.x 会直接报错，网上的教程大半已经过时 |

这份教程的做法是保留官方的组织顺序，在每一节后面补上同一个项目里的实现，并把实测结果（启动耗时、jar 体积、镜像层大小、内存占用、测试耗时）写进正文。遇到拿不准的地方，可以顺着每篇开头的官方章节链接回原文核对。

| 官方章节 | 页面数 | 本教程对应 |
| --- | --- | --- |
| Getting Started / Tutorial | 3 | 第 1 篇 |
| Reference → Using Spring Boot | 10 | 第 1、2、11 篇 |
| Reference → Core Features | 14 | 第 3 篇 |
| Reference → Web | 8 | 第 4、5 篇 |
| Reference → Data | 3 | 第 6 篇 |
| Reference → I/O | 11 | 第 7 篇 |
| Reference → Messaging | 8 | 第 8 篇 |
| Reference → Testing | 7 | 第 9 篇 |

| How-to Guides | 25 | 各篇的"常见问题"小节 |
| Specification / Appendix | 40+ | 附录与速查 |

教程没有漏掉官方任何一章，边缘技术（gRPC、Hazelcast、Pulsar 等）以"要点 + 最小可运行示例"的方式收录。

## 适合谁读

- 学过 Java 基础、会用 Maven，但没完整做过一个 Spring Boot 项目的学生；
- 从 Spring Boot 2.x / 3.x 上来，需要知道 4.x 有哪些破坏性变更的开发者；
- 需要一份能直接给课堂用的实训材料，要求代码可运行、结果可复现的老师。

前置要求：Java 17 及以上、Maven、能跑 Docker（第 9 篇的 Testcontainers 与第 11 篇的容器化会用到）。环境准备见[第 0 篇的环境准备](/ch00/03)。

## 怎么用这个站点

| 想做的事 | 怎么做 |
| --- | --- |
| 按顺序学 | 左侧边栏按"阶段 → 篇 → 小节"组织，从[第 0 篇](/ch00/)往下走 |
| 查某个知识点 | 右上角的搜索框支持全文检索，中文可用 |

| 换个角度看代码 | 右上角可切换深色模式；正文里的代码块带语言标注，可直接复制 |
| 打印或存成 PDF | 打印样式会去掉导航与侧边栏，只留正文 |

## 关于版本

官方文档站 `docs.spring.io/spring-boot/` 默认指向当前 GA 版本，即 4.1.x。教程里所有"官方原文"的引用都来自该版本，链接可以直接点开核对。

::: warning 版本会变
版本号属于易变信息，通常半年内会有小版本更新。若在几个月后阅读，先到官方的 [System Requirements](https://docs.spring.io/spring-boot/system-requirements.html) 确认当前要求，再对照本地工程的启动日志。正文里的写法（注解、API、配置项）比版本号稳定得多。
:::

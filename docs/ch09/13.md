# 9.13 问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 编译报“找不到符号 `MockMvc`” | 少了 `spring-boot-starter-webmvc-test` | 补测试 starter 依赖 |
| `@WebMvcTest` import 不到 | 4.x 换了包 | 用 `org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest` |
| `@DataJpaTest` import 不到 | 4.x 换了包 | 用 `org.springframework.boot.data.jpa.test.autoconfigure.DataJpaTest` |
| `@MockBean` 编译不过 | 4.x 已删除该注解 | 改用 `@MockitoBean` / `@MockitoSpyBean` |
| 切片测试里 Service 注入为 null | 切片不扫描 `@Service` | 用 `@MockitoBean` 补假对象 |
| 切片测试想连数据库连不上 | `@WebMvcTest` 不含数据层 | 换成 `@DataJpaTest` 或 `@SpringBootTest` |
| 想在一个测试里用两个切片注解 | 不支持混用 | 选一个 `@...Test`，其余用 `@AutoConfigure...` 补 |
| 参数校验失败返回 500 而不是 400 | `@RestControllerAdvice` 没被扫描到 | 检查它是否在切片的扫描范围内 |
| `.extractingPath(...)` 链式写两遍编译不过 | 返回的是值断言，不是内容断言 | 先把 `bodyJson()` 的结果存下来，再逐个提取 |
| `TestRestTemplate` 找不到类 | 4.x 搬了模块和包 | 引 `spring-boot-resttestclient`，用 `org.springframework.boot.resttestclient.TestRestTemplate` |
| `TestRestTemplate` 注入不进来 | 少 `spring-boot-restclient` | 补上（官方文档明确要求） |
| 真实端口测试数据没回滚 | 请求与测试在不同线程、不同事务 | 用例自己保证数据唯一并清理 |
| 端口固定导致测试互相抢 | 用了 `DEFINED_PORT` | 换 `RANDOM_PORT` + `@LocalServerPort` |
| 编译报找不到 `MySQLContainer` | 2.0 把数据库容器移出了 core | 引 `org.testcontainers:testcontainers-mysql` |
| `MySQLContainer` 泛型用法编译不过 | 2.0 去掉了自引用泛型 | 不要写 `MySQLContainer<>`，直接 `new MySQLContainer(“mysql:8”)` |
| 升了 Boot 但 Testcontainers 还是 1.21 | 老坐标不会自动跟着升 | 把 `org.testcontainers:mysql` 换成 `testcontainers-mysql` |
| Testcontainers 卡在 `Retrying pull for ryuk` | 拉不到 `testcontainers/ryuk` | 配镜像加速器，或临时 `TESTCONTAINERS_RYUK_DISABLED=true` |
| 容器被停掉后连接报错 | 容器由 Testcontainers 管，关闭顺序无保证 | 改成容器 Bean（Spring 管生命周期） |
| `@ServiceConnection` 不生效 | 用了 `GenericContainer` 但没写名字 | `@ServiceConnection(name = “mysql”)` |
| H2 能跑、MySQL 报错 | 方言/字符集/约束差异 | 这类用例放到 Testcontainers 层 |

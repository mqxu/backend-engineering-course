# 十三、常见问题

| 症状 | 原因与解法 |
| --- | --- |
| 加了 `@EnableWebMvc` 后静态资源 404 | 删掉这个注解，改为实现 `WebMvcConfigurer` |
| `@RequestParam` 上的 `@Min` 不生效 | 类上漏了 `@Validated` |
| `@Valid @RequestBody` 不生效 | 注解加在了 Controller 方法上，应该加在参数上；或 DTO 是普通类但没写 getter（record 无此问题） |
| 枚举传错值返回 500 | 补 `HttpMessageNotReadableException` 的处理分支 |
| 上传返回 500 而不是 413 | 补 `MaxUploadSizeExceededException` 的处理分支；或确认 `max-file-size` 配置生效 |
| 上传大文件报 1MB 超限 | Spring Boot 默认上限就是 1MB，改 `spring.servlet.multipart.max-file-size` |
| 图片不显示、浏览器直接下载 | 响应少了 `Content-Type`，`mediaTypeOf` 没按后缀返回图片类型 |
| 后缀合法但内容不是图片 | 只校验了后缀，没有校验文件头魔数 |
| 管理端点报 `package does not exist` | 4.x 模块拆分导致包名迁移，见第 0 篇的包名迁移表 |
| 跨域报错 `Allow-Origin: *` 与凭证冲突 | `allowCredentials(true)` 时来源必须逐个列出 |
| 分页出现重复或遗漏记录 | 排序键不唯一，加上 `id` 作为第二排序键 |
| 停机时请求被中断 | 配 `server.shutdown: graceful`，并确认发的是 `SIGTERM` 不是 `SIGKILL` |
| `page` 参数前端从 1 开始传，后端从 0 开始理解 | 统一约定并在文档里写明；MyBatis-Plus 恰好相反，见第 6 篇 |

> **下一篇要做什么**
>
> 接口能用了，但任何人不登录就能新增和删除——这显然不能上线。第 5 篇对照官方的 Security 章节，给这套接口加上认证与授权：Spring Security 6 的过滤链配置、JWT 无状态认证、密码加密、角色与权限控制，以及前后端联调时的登录接口设计。

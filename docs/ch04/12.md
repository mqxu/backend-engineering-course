# 十二、本章实测汇总

| 场景 | 命令要点 | 结果 |
| --- | --- | --- |
| 分页查询 | `GET /api/activities?page=1&pageSize=2` | 200，返回 `list/total/page/pageSize` |
| 关键词搜索 | `?keyword=程序` | 命中数随数据变化，大小写无关 |
| 新增 | `POST /api/activities` | 200，`data` 是新活动的 id |
| 详情不存在 | `GET /api/activities/9999` | 200，`2001` |
| 发布活动 | `PATCH /api/activities/{id}/status` | 200 |
| 上传封面图 | `POST /api/files/covers` | 200，返回可访问路径，磁盘出现 UUID 文件名 |
| 读取封面图 | `GET /api/files/covers/{name}` | 200，`Content-Type: image/png`，字节一致 |
| 上传超限 | 传 6MB（限 5MB） | **413**，`5002` |
| 路径穿越 | `/api/files/covers/..%2F..%2F..%2Fetc%2Fpasswd` | 400（被 Tomcat 拦截，HTML 错误页） |
| 封面图不存在 | `/api/files/covers/notexist.png` | 404，`1004` |
| CORS 预检 | `OPTIONS` + `Origin` | 200，返回 5 个 `Access-Control-*` 头 |
| 拦截器 | 观察应用日志 | `GET /api/activities → 200 (115 ms)` |

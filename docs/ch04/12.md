# 十二、本章实测汇总

| 场景 | 命令要点 | 结果 |
| --- | --- | --- |
| 分页查询 | `GET /api/resources?page=0&size=2` | 200，返回 `items/page/size/total/totalPages` |
| 关键词搜索 | `?keyword=spring` | 命中 2 条，大小写无关 |
| 新增 | `POST /api/resources` | **201**，返回带 id 的完整对象 |
| 校验失败 | `title` 传 `"  "` | 400，`40001`，一次性返回全部字段错误 |
| 参数越界 | `?page=-1` | 400，`40001`，“页码不能小于 0” |
| 枚举非法 | `type: "PODCAST"` | 400，`40002`，不是 500 |
| 同名冲突 | 重复标题新增 | 409，`40900` |
| 详情不存在 | `GET /api/resources/9999` | 404，`40400` |
| 上传 | `POST /api/files` | 201，磁盘出现文件 + `.meta` |
| 下载 | `GET /api/files/{name}` | 200，`Content-Disposition: attachment`，字节一致 |
| 上传超限 | 传 30MB（限 20MB） | **413**，`41300` |
| 路径穿越 | `/api/files/..%2F..%2F..%2Fetc%2Fpasswd` | 400（被 Tomcat 拦截） |
| 文件不存在 | `/api/files/notexist.txt` | 404，`40400` |
| CORS 预检 | `OPTIONS` + `Origin` | 200，返回 5 个 `Access-Control-*` 头 |
| 拦截器 | 观察应用日志 | `GET /api/resources → 200 (115 ms)` |

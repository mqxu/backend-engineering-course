# 十一、优雅停机

```yaml
server:
  shutdown: graceful

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s
```

默认 `shutdown: immediate`，收到停机信号后直接关闭，正在处理的请求会被中断——用户看到连接重置。改成 `graceful` 后：

1. 停止接受新请求（这些请求收到 503）；
2. 给正在处理的请求留出完成时间；
3. 超时（`timeout-per-shutdown-phase`）后强制关闭。

**为什么重要**：容器滚动升级时会先发停机信号再杀进程。没有优雅停机，每次发布都会有一批用户请求失败。

> **前提是接对了信号**
>
> 优雅停机监听的是 JVM 的 shutdown hook，对应 `SIGTERM`。`java -jar` 直接按 `Ctrl+C`（`SIGINT`）也会触发。但 `kill -9`（`SIGKILL`）不走 hook，配置再对也没用。容器编排里要确认发的是 `SIGTERM`。

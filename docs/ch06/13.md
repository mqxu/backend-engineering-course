# 十三、常见问题

| 症状 | 原因与解法 |
| --- | --- |
| `DataSource` 注入不进来 | 只引了 `spring-boot-starter-web`，缺 `starter-jdbc` 或 `starter-data-jpa` |
| 启动报 `Not a managed type` | 实体不在主类所在包及其子包下，加 `@EntityScan` |
| 表不存在 / 启动时报 table not found | 连的是非嵌入式库，`ddl-auto` 默认为 `none`；用 Flyway 或手工建表 |
| `data.sql` 报表不存在 | 缺 `spring.jpa.defer-datasource-initialization: true` |
| 连 MySQL 但 `data.sql` 没执行 | `spring.sql.init.mode` 默认是 `embedded`，要改成 `always` |
| 脚本里 `#` 注释导致语法错误 | 初始化脚本只认 `--` 和 `/* */` |
| 列名对不上（如 `category_id` 与 `categoryId`） | JPA 靠 `@Column` / 命名策略；MyBatis-Plus 开 `map-underscore-to-camel-case` |
| 接口慢但看不到明显问题 | 查 Hibernate SQL 日志数条数，大概率是 N+1（第八节） |
| `LazyInitializationException` | 在事务外访问了 LAZY 关联。要么把取值放事务内，要么改用 DTO 投影 |
| 改了字段没写库 | 忘了 `@Transactional`，或方法被自调用绕过了代理（第七节） |
| 受检异常不回滚 | `@Transactional` 默认只回滚运行时异常，加 `rollbackFor` 或转成业务异常 |
| `Expecting a SELECT query` | `@Modifying` 注解缺失 |
| 批量 UPDATE 后查到旧值 | `@Modifying` 缺 `clearAutomatically = true` |
| 枚举值莫名变了含义 | 用了默认的 `EnumType.ORDINAL`，改成 `STRING` |
| 下载量可能少算 | 用了读-改-写，改成原子 UPDATE（第九节） |
| 想批量插入但很慢 | 主键用了 `IDENTITY`，Hibernate 无法批量化，换 `SEQUENCE` 或 UUID |
| `ClassNotFoundException: net.sf.jsqlparser...` | MyBatis-Plus 缺 `mybatis-plus-jsqlparser` 模块 |
| MyBatis-Plus 分页返回全部数据 | 忘了注册 `PaginationInnerInterceptor`（第 11.5 节，附实测） |
| 分页第一页少一条 / 最后一页为空 | 页码起点搞混：Spring Data 从 0，MyBatis-Plus 从 1 |
| 启动报找不到自动配置类 | MyBatis-Plus starter 用错了版本后缀（`spring-boot3` 与 `spring-boot4`） |

> **下一篇要做什么**
>
> 数据落盘了，接口也稳了。第 7 篇处理“性能与外部依赖”这一层：用 `@Cacheable` 把热点查询挡在数据库前面（含缓存穿透、雪崩的应对），用 `RestClient` 稳定地调用第三方接口（超时、重试、异常映射），以及参数校验的进阶用法、邮件发送和定时任务。

# 十、H2 控制台

开发期最实用的工具，能直接查表验证数据：

```yaml
spring:
  h2:
    console:
      enabled: true
      path: /h2-console
```

浏览器打开 `http://localhost:8080/h2-console`，连接信息填 yml 里的 url（`jdbc:h2:mem:resourcehub`）、用户名 `sa`、密码留空。

两个条件要注意：

- **只在 Servlet Web 应用里生效**，且需要 `spring-boot-h2console` 模块在类路径上（引 `h2` 时通常已带上）。不满足条件时，上面的显式 `enabled: true` 才能打开它。
- **在启用了安全的应用里，必须放行并允许 iframe**。本项目在 `SecurityConfig` 里做了两件事：

```java
.requestMatchers("/h2-console/**", "/error").permitAll()
// ...
.headers(headers -> headers.frameOptions(frame -> frame.sameOrigin()))
```

第二行不能省——H2 控制台用 iframe 布局，默认的 `X-Frame-Options: DENY` 会让页面一片空白。

> **生产环境务必关掉**
>
> H2 控制台不带任何认证，任何人访问到就是数据库的最高权限。用 H2 的 File 模式部署时这是致命的。

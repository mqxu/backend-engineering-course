# 十二、NoSQL 要点

官方 NoSQL 章节覆盖的技术，以及选型判断：

| 技术 | 解决什么问题 | 什么时候不该用 |
| --- | --- | --- |
| Redis | 缓存、分布式锁、计数器、会话共享 | 当主数据库用——持久化和查询能力都不合适 |
| MongoDB | 文档型数据、字段不固定的场景（日志、表单、内容） | 需要多表事务的强一致业务 |
| Elasticsearch | 全文检索、日志分析、聚合统计 | 当主数据库用；写入量大但不需要检索时成本过高 |
| Cassandra | 海量写入、多数据中心 | 需要复杂查询和事务 |
| Neo4j | 图关系（社交网络、推荐路径） | 关系简单时纯属增加复杂度 |

Spring Boot 对它们的接入方式一致：加对应的 `spring-boot-starter-data-*` 依赖，配 `spring.data.<技术>.*`，用 Spring Data 的 Repository 接口。

**本项目没有引入任何 NoSQL**（缓存那一块在第 7 篇讲 `@Cacheable` 时用简单的内存实现说明原理）。原因很实际：教学项目的重点是让每个概念都能在本机跑起来、看得见效果；引入 Redis 就把环境依赖带进来了。需要上手时，官方 how-to 章节有各技术的完整示例。

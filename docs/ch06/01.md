# 一、官方 Data 一章覆盖了什么

官方的 Data 章节本身只有一句话——“Spring Boot 集成了多种数据技术，包括 SQL 与 NoSQL”，然后分成两大棵树：

| 分支 | 官方覆盖的技术 | 本篇处理方式 |
| --- | --- | --- |
| SQL | 数据源与连接池、`JdbcTemplate` / `JdbcClient`、JPA、Spring Data JDBC、H2 控制台、jOOQ、R2DBC | 重点讲数据源、`JdbcClient`、JPA 三条，R2DBC 与 jOOQ 简要带过 |
| NoSQL | Redis、MongoDB、Elasticsearch、Cassandra、Neo4j、LDAP、InfluxDB | 第十二节给选型要点，案例项目未引入，不做实测 |

MyBatis-Plus 不在官方文档里——Spring Boot 官方只原生支持 JPA 与 Spring Data JDBC，MyBatis 是第三方生态。所以第十一节的内容全部来自 MyBatis-Plus 官方文档与本机实测。

### 1.1 案例项目的数据访问设计

本项目的两个工程分别用两种技术实现同一套接口，可以直接对照：

| | `activity-server` | `activity-server-mybatisplus` |
| --- | --- | --- |
| 端口 | 8080 | 8081 |
| 映射方式 | JPA 注解 + Hibernate 自动建表 | MyBatis-Plus 注解 + 手写建表脚本 |
| 数据访问 | `JpaRepository` + `Specification` | `BaseMapper` + `LambdaQueryWrapper` |
| 表结构 | `ddl-auto: create-drop` 由框架生成 | `schema.sql` 人工维护 |
| 逻辑删除 | 实体方法里手工置位 | `@TableLogic` 由框架改写 SQL |
| 测试数 | 42（第 7 篇新增 16 个，总计 58） | 6 |
